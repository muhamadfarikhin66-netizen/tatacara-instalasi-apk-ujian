Siapkan izin dulu, baru ketuk file · Ikuti langkahnya berurutan

📱 Aplikasi ini aman, dibuat oleh sekolah, tetapi bukan dari Play Store. Karena itu HP akan meminta izin khusus dan bisa menampilkan peringatan. Itu normal. Ikuti panduan ini dan jangan panik.
Urutannya: ① siapkan izin → ② unduh file → ③ ketuk file → ④ instal → ⑤ tutup izin kembali.

3Ketuk file APK, atasi peringatan keamanan

Sekarang ketuk file Aplikasi Ujian.apk di chat WhatsApp. Ini yang paling sering membuat siswa bingung. Android dan Google Play Protect bisa memunculkan salah satu layar di samping. Pilihan yang benar selalu yang kecil dan tidak mencolok, bukan tombol biru besar.

  1. “Pengembang tidak terverifikasi” / “Aplikasi ini mungkin berbahaya” → ketuk Detail lainnya lalu Tetap instal / Instal saja.
  2. “Pindai aplikasi dengan Play Protect” → ketuk Instal tanpa memindai, atau Pindai aplikasi lalu tunggu hasilnya, kemudian pilih Tetap instal.
  3. “Aplikasi diblokir” / “App blocked” → ketuk OK, lalu coba ulang dari awal (Langkah 1). Jika tetap diblokir, lapor ke guru.
  4. Xiaomi: jika muncul “Verifikasi keamanan” atau hitungan mundur, tunggu selesai lalu pilih Lanjutkan instal / Instal.
Untuk guru: jika HP tetap menolak, Play Protect bisa dimatikan sementara: Play Store → ikon profil → Play Protect → ⚙ → matikan Pindai aplikasi dengan Play Protect. Setelah instal nyalakan kembali.

4Pasang aplikasi

  1. Setelah peringatan (jika ada) selesai, layar pemasangan akan terbuka.
  2. Ketuk Instal.
  3. Tunggu sampai muncul “Aplikasi terpasang”.
  4. Ketuk Buka.
Alternatif: buka File Manager → Download (atau folder WhatsApp → Documents), lalu ketuk Aplikasi Ujian.apk.

5Matikan kembali izin jika sudah selesai

Terakhir, tutup lagi izin yang tadi dibuka di Langkah 1 agar HP tetap aman.

  1. Buka kembali menu Instal aplikasi tidak dikenal (jalur sama seperti Langkah 1).
  2. Pilih WhatsApp.
  3. Matikan tombol Izinkan dari sumber ini.

💡 Jika masih gagal

  • “Aplikasi tidak terpasang” → hapus dulu aplikasi ujian versi lama (jika ada), lalu instal lagi.
  • Memori penuh → kosongkan minimal 100 MB.
  • Tombol Instal abu-abu / tidak bisa diketuk → tunggu beberapa detik, atau tutup lalu buka ulang file APK.
  • File APK tidak bisa dibuka → unduh ulang dari WhatsApp (ukuran harus penuh, ±15 MB).
  • Pastikan aplikasi hanya dari guru / sekolah. Jangan instal dari sumber lain.
  • Masalah lain? Segera lapor ke guru.
